# ☕ Cafetería Aroma - Sistema Web de Gestión

Aplicación web dinámica desarrollada en **PHP**, **MySQL**, **HTML5** y **CSS3** para la gestión de una cafetería. Permite a los clientes consultar el menú por categorías, realizar reservas de mesas y enviar mensajes de contacto, además de contar con un panel administrativo funcional para gestionar toda la base de datos desde el navegador.

## 📁 Estructura del Proyecto

```text
Cafeteria/
├── config/             # Conexión a base de datos MySQL (conexion.php)
├── css/                # Hojas de estilo (estilos.css)
├── paginas/            # Vistas dinámicas (menu.php, reservas.php, contacto.php, admin.php)
├── base_de_datos.sql   # Script SQL de creación de tablas y datos iniciales
└── index.php           # Página principal
